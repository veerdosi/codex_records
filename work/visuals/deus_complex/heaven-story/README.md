# This must be heaven · Instagram Story

A 59-second, 1080 × 1920 Story for DUES COMPLEX. It opens with a 5.5-second personal note, plays 48 seconds of the music film, and closes with a 5.5-second YouTube card. The main music selection runs from 36.571428571 to 84.571428571 seconds in the approved master. Quiet instrumental passages sit beneath the text cards.

The stadium photo behind the album artwork supplies the image plates. Separate shots explore roof structure, the performer, dome texture, fractured exposures, contact prints, and an eclipse. Cuts land on the song’s two-bar boundaries at 105 BPM. The palette opens from blue-green to amber at the chorus return. The closing card uses the thumbnail and channel name cropped from the user’s YouTube screenshot.

## Prepare and preview

From the repository root, prepare the image plates, grain, beat envelope, and local audio excerpt.

```sh
work/shared/environments/audio-venv/bin/python work/visuals/deus_complex/heaven-story/prepare.py
```

From this folder, install the pinned dependencies and open the editable timeline.

```sh
npm ci
npm run dev
```

The Remotion scenes, their timing, title typography, and accent colors are editable in Studio. The beat envelope and deterministic grain textures are generated by `prepare.py`.

## Render

Run from this folder.

```sh
npx remotion render HeavenStory '../../../../outputs/deus complex/visuals/ig/this_must_be_heaven_story.mp4' --codec=h264 --crf=20 --pixel-format=yuv420p --audio-bitrate=320k --audio-codec=aac --x264-preset=medium --concurrency=3 --license-key=free-license
```

The finished MP4 stays in the local outputs folder. The music excerpt is generated locally and excluded from Git. The Instrument Serif and Archivo Narrow fonts include their OFL notices in `public/fonts/`.
